# PPT 内联浏览 — 实施总结

> 日期：2026-06-06 | 状态：已完成

---

## 功能概述

用户上传 PPTX 或 CLI Agent 生成 PPTX 后，后端自动调用 Gotenberg（LibreOffice headless）将 PPTX 转换为 PDF，前端复用 DocumentCard 已有的 PDF iframe 渲染，实现内联预览。转换失败时降级为下载按钮。

---

## 后端转换管线

```
PPTX 来源
    │
    ├─ 用户上传: POST /api/v1/files/upload
    │    → 存 MinIO (files/{uuid})
    │    → upload 端点即时转 PDF → MinIO (conversions/{id}.pdf)
    │    → 前端发送消息时 prompt 含 fileUrl
    │    → SSE message_end 时 artifact_detector 扫描 prompt
    │    → _resolve_internal_file 识别内部文件 URL
    │    → _maybe_convert_pptx 调 Gotenberg 转换
    │
    ├─ Agent 回复中的文档 URL
    │    → _detect_urls → _is_document_url → _maybe_convert_pptx
    │
    └─ CLI Agent 本地生成文件
         → _emit_cli_generated_file_artifacts 扫描 workspace
         → 上传 MinIO → _maybe_convert_pptx
    │
    ▼
_maybe_convert_pptx()
    ├─ MinIO 读取 pptx 字节
    ├─ POST Gotenberg /forms/libreoffice/convert
    ├─ PDF 存 MinIO (files/{new-uuid}) → fileUrl=/api/v1/files/{id}/download
    └─ 失败则保留原始 fileType 降级
    │
    ▼
SSE artifact 事件 (artifactType=document, fileType=pdf)
    │
    ▼
前端 DocumentCard: fileType=pdf → <iframe src={fileUrl} />
    │
    ▼
files.py download 端点: Content-Type=application/pdf, Content-Disposition=inline
```

## PPT 生成

CLI Agent（Claude Code CLI）能通过 `python-pptx` 库生成真正的 `.pptx` 文件：

1. 用户在 AgentHub 中选择 **Claude Code CLI** Agent
2. 发送 prompt：`请用 python-pptx 生成一个产品介绍 PPT，保存为 demo.pptx`
3. Claude Code CLI 在 `cli-workspace/` 目录中写 Python 脚本并执行
4. 本地生成 `demo.pptx` 文件
5. 后端扫描 workspace，自动上传 MinIO → Gotenberg 转 PDF → 前端 DocumentCard 预览

LLM Agent（如代码助手Marisa）只能**写** python-pptx 代码文本，不能执行，无法产出文件。

## 内联渲染

复用 DocumentCard 已有的 PDF iframe 渲染路径：

```tsx
// DocumentCard.tsx — 无需新增分支，pptx 后端已转为 pdf
c.fileType === "pdf" || c.fileType === "pptx" ?
  <iframe src={c.fileUrl} style={{ width: "100%", height: "100%", border: "none" }} />
```

`files.py` 下载端点对 PDF 文件返回 `Content-Type: application/pdf` + `Content-Disposition: inline`，浏览器内嵌 PDF 阅读器接管渲染，支持翻页、缩放、搜索。

## 联调中修复的 Bug

| # | 症状 | 根因 | 修复 |
|---|------|------|------|
| 1 | Gotenberg 502 | httpx 走 Windows 系统代理 | 所有 httpx 客户端加 `trust_env=False` |
| 2 | Gotenberg 400 | 文件名无扩展名，LibreOffice 无法识别 | `_resolve_internal_file` 加扩展名 |
| 3 | 转换成功但弹下载框 | `Content-Disposition: attachment` | PDF 设 `inline` |
| 4 | uvicorn reload 打断 CLI | workspace 在 backend/ 内 + venv 变更触发重载 | workspace 外移 + `--reload-exclude` |
