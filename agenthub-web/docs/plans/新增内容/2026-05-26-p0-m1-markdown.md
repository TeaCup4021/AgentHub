# P0 M1 — Markdown 渲染 + 代码高亮 实施计划

日期：2026-05-26 | 状态：已完成

## 目标

替换 TextBubble（纯 `<p className="whitespace-pre-wrap">`）为 react-markdown 完整渲染，代码块使用 shiki 语法高亮。

## 文件变更

| 操作 | 文件 | 说明 |
|------|------|------|
| 新增 | `src/components/chat/HighlightedCode.tsx` | shiki 代码高亮共享组件 |
| 新增 | `src/components/chat/MarkdownBubble.tsx` | react-markdown 封装 |
| 重写 | `src/components/cards/CodeCard.tsx` | 委托 HighlightedCode |
| 修改 | `src/components/chat/MessageList.tsx` | 替换 TextBubble → MarkdownBubble |

## 技术选型

- **shiki v4 + JavaScript 引擎**：`createHighlighterCore` + `createJavaScriptRegexEngine`，无需 WASM
- **17 种语言**：ts/tsx/js/jsx/python/rust/go/java/css/html/json/yaml/bash/markdown/sql/diff
- **插件**：`remark-gfm` + `rehype-raw`
- **代码折叠**：超过 30 行自动折叠
