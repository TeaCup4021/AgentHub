# Diff 卡片双栏审阅视图

日期: 2026-06-09
状态: Implementing

## 目标

将 Diff artifact 从 Monaco 默认差异编辑器重构为 AgentHub 自有的双栏代码审阅卡片。卡片主体固定分为左右两个板块，左侧为源代码，右侧为修改后代码，并通过颜色标记新增、删除和修改内容。

## 用户体验

- 默认展示并排双栏视图，不再把统一视图作为主要入口。
- 顶部栏保留文件名、语言、真实新增/删除统计、应用到源文件、另存为文件、全屏、恢复大小。
- 左侧板块标题为“源代码”，右侧板块标题为“修改后”。
- 删除内容使用红色标记，新增内容使用绿色标记，修改内容使用浅黄行底并在具体变化文本上叠加红/绿强调。
- 双栏共享滚动容器，保证行高和上下文位置对齐。
- 连续大量未修改代码可折叠为一条上下文提示，减少卡片噪音。
- 窄屏或小卡片下仍保持双栏语义，通过横向滚动保证代码不被挤压。

## 实现范围

| 文件 | 说明 |
| --- | --- |
| `src/lib/diff.ts` | 扩展 side-by-side diff 数据模型、真实统计、行内变化片段 |
| `src/components/cards/SideBySideDiffViewer.tsx` | 新增纯展示组件，负责双栏渲染 |
| `src/components/cards/DiffCard.tsx` | 保留业务操作，替换主体 diff 视图 |
| `src/index.css` | 新增双栏 diff 视觉样式 |

## 非目标

- 本次不引入新的后端字段。
- 本次不改变 Diff artifact 的 `oldCode/newCode/fileName/language` 数据结构。
- 语法高亮可在后续迭代接入 Shiki 或 Monaco token，不阻塞本次双栏审阅体验。
