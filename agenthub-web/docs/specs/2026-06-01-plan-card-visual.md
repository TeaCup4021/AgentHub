# Spec: 计划卡片视觉优化

**日期**: 2026-06-01  
**状态**: review  
**关联**: OrchestratorPlan 按钮、配色、编辑态 UI 质感提升

---

## 动机

当前 OrchestratorPlan 大面积使用 `var(--color-primary)` 蓝色：数字圈蓝底白字、agent 名蓝色、确认按钮蓝色填充。显得"大蓝大红"，和 Claude Code/ChatGPT 等主流平台克制的灰度体系不一致。

## 设计原则

- **灰度层级替代颜色喊叫**：强调靠字体粗细、灰度深浅、间距留白
- **颜色只做点缀**：蓝色仅保留在 SVG 图标和 6px 状态圆点
- **按钮不抢注意力**：确认用深灰、编辑用灰描边、对话用灰字

## 配色对照

| 元素 | 改前 | 改后 |
|------|------|------|
| 数字圈背景 | `var(--color-primary)` 蓝 | `#e5e7eb` 灰 |
| 数字圈文字 | 白色 | `#6b7280` 深灰 |
| Agent 名 | `var(--color-primary)` 蓝 | `#4b5563` 深灰 |
| 确认按钮 | solid primary 蓝填充 | `#1f2329` 深灰填充，圆角 6px |
| 手动编辑按钮 | light 蓝描边 | `#e5e7eb` 灰描边 + `#4b5563` 字 |
| 对话修改按钮 | borderless 蓝字 | `#9ca3af` 灰字 + 对话图标 |
| 任务列表底色 | `var(--color-bg-hover)` | 白底 + 极淡分割线 `#f3f4f6` |
| 编辑中标签 | `var(--color-warning)` 橙 | `#9ca3af` 灰标签 |
| 编辑态行底色 | `var(--color-bg-elevated)` | `rgba(0,0,0,0.02)` 极淡灰 |
| 模式标签 | `var(--color-primary)` 蓝 | `#6b7280` 灰徽章 |
| 删除按钮 | `type="danger"` 红 | `#9ca3af` 灰 ×，hover 变 `#ef4444` |

## 按钮层级

```
预览态:  [💬 对话修改]   [✎ 手动编辑]   [▶ 确认执行]
          灰字无背景      灰描边圆角       深灰填充圆角
          
编辑态:  [取消]   [保存修改]
         灰字      深灰填充
```

## 文件变更

| 文件 | 改动 |
|------|------|
| `OrchestratorPlan.tsx` | 全面替换配色、调整按钮层级、优化间距和分割线 |

## 非目标

- 不改功能逻辑（编辑、refine、confirm 行为不变）
- 不改计划卡片的嵌入方式（已是消息气泡内嵌）
- 不改其他组件

## 验收标准

1. 预览态计划卡片无大面积蓝色（仅图标保留蓝色）
2. 确认执行为深灰色填充按钮，视觉权重最高
3. 编辑态行和预览行底色明显区分
4. 按钮层级清晰：确认 > 编辑 > 对话
5. `npx tsc -b --noEmit` 零错误
6. `npx vitest run` 全部通过
