# AgentHub 前端优化任务清单

基于代码审查的完整功能模块按 P0/P1/P2 分级，共计 23 个模块。

## P0 — 核心体验链路（不修就没法演示）

| # | 模块 | 现状 | 目标 |
|---|------|------|------|
| 1 | Markdown 渲染 + 代码高亮 | TextBubble 纯文本 `<p>` 标签，代码块无高亮 | react-markdown + rehype-highlight + remark-gfm，代码块语法高亮 + 一键复制 |
| 2 | 消息列表自动滚底 | 新消息出现在视口外，需手动滚 | 新消息自动滚底；用户上滚查看历史时出现「回到底部」浮动按钮 |
| 3 | 消息时间戳 | 消息气泡无任何时间信息 | 每条消息显示发送时间（hover 精确时间 / 气泡旁短时间） |
| 4 | 全局 Toast 通知 | 错误全走 console.error，用户看不到 | sonner / shadcn Toast，覆盖：发送失败、SSE 断开、创建成功/失败、重连提示 |
| 5 | Mock 新对话可用 | 新建对话后发消息，无 SSE 回复返回 | Mock 模式下新建对话能产生完整 SSE 事件序列的模拟回复 |
| 6 | SSE 断连 UI 反馈 | 断连静默，重连也不提示 | 断连时顶部 Banner「连接已断开，正在重连...」，重连成功/失败有反馈 |

## P1 — 体验完整度（让产品像个产品）

| # | 模块 | 现状 | 目标 |
|---|------|------|------|
| 7 | 暗色模式 | uiStore 有 theme 字段但零组件读取 | Tailwind darkMode: 'class' + 全面适配（侧边栏、气泡、卡片、设置页） |
| 8 | 代码块增强 | 灰底白字纯 `<pre>` | 语言标签、行号、一键复制、文件标题 bar（类 GitHub Gist 风格） |
| 9 | Agent 管理完整化 | 只能创建，无编辑/删除/详情 | Agent 列表页：卡片网格 + 搜索 + 筛选；编辑模态框；删除确认；Agent 详情抽屉 |
| 10 | 消息操作 | 无任何消息级操作 | hover 出现操作栏：重新生成、复制文本、引用回复 |
| 11 | 会话功能补全 | 右键菜单只有置顶/重命名/归档/删除 | 增加：会话内搜索、批量归档、会话导出（Markdown） |
| 12 | 空状态 & 加载态 | 大面积空白或一句灰字 | 会话列表空状态插画 + 引导文案；消息列表首次加载骨架屏 |
| 13 | 响应式基础 | 固定 w-80 侧边栏 | 侧边栏可拖拽调整宽度；768px 以下折叠为移动端布局 |
| 14 | 聊天输入增强 | 纯文本 contentEditable | 支持粘贴图片（截图）、拖拽文件、输入框高度自适应、字数统计 |
| 15 | Token 用量图表 | 三张数字卡片 + 静态表格 | recharts 折线图（按日期）+ 饼图（按 Agent）+ 柱状图（按会话） |

## P2 — 差异化亮点（让评审记住你）

| # | 模块 | 现状 | 目标 |
|---|------|------|------|
| 16 | 群聊 Orchestrator 全链路 | 只有 OrchestratorPlan 静态卡片 | 完整闭环：发送群聊消息 → Orchestrator 返回计划 → 用户确认 → 多 Agent SSE 交织 → 聚合汇总 |
| 17 | ReAct 推理面板 | ThinkingBlock 埋在消息气泡内 | 可拖拽的全局侧边面板，实时展示 thought/action/observation 步骤 |
| 18 | 产物工作台 | 产物散落在聊天流中 | 每个会话一个「产物」Tab，汇总所有 Agent 产出的代码/文件/预览，可筛选、排序 |
| 19 | Agent 对话式创建 | 只能表单创建 | 聊天中说「帮我创建测试 Agent」→ 自动分析需求 → 生成配置预览 → 一键确认 |
| 20 | 会话分支 | 消息流是线性的 | 在任意消息处「从这里分支」，创建新会话但保留上文完整上下文 |
| 21 | @提及增强 | 已有基础补全 | 支持 @Agent名 具体指令格式解析，群聊中可给不同 Agent 分配不同子任务 |
| 22 | 首页/落地页 | 无，应用直接进聊天 | 欢迎页：项目介绍、快捷操作入口（新建对话/浏览 Agent/查看产物）、最近会话预览 |
| 23 | 微动效打磨 | 仅三个点的 bounce | 消息出现动画、发送按钮状态过渡、卡片展开/收起、页面切换过渡、流式打字光标 |

共计 23 个模块。P0 是底线——没有 Markdown 渲染和自动滚底的聊天应用不是聊天应用。P1 决定你的产品看起来像 2026 年的东西还是 2016 年的东西。P2 是和你同台竞争的队伍大概率不会做的东西，是你拿「创新与产品感」那 10% 分数的关键。
